Artificial Intelligence Containment Assurance Levels(AI-CAL) - AI Agent Containment Framework

AI-CAL is a security architecture framework focused on containment, control boundaries, and assurance for AI agents and related autonomous systems.

The framework is intended to support practical security architecture, design review, risk analysis, Assurance levels, and implementation planning.
